# Отчет по лабораторной работе №7

## 1. Модели и репозитории
Модели User и Order созданы. В User есть поле email, balance и связь orders. В Order есть user_id, amount, status.

## 2. Миграции
- `123456789abc` — создает таблицы users и orders.
- `abcdef123456` — добавляет колонку status с server_default='pending'.
При откате (downgrade) колонка удаляется, значения теряются.

## 3. Атомарное создание заказа
В функции create_order списание баланса и создание заказа происходят в одной транзакции. Тест с ошибкой подтвердил, что при исключении откатываются оба изменения.

## 4. N+1
Запущен тест с замером запросов на 3-х пользователях:
- Наивный вариант: 4 запроса (1 + N).
- Исправленный с selectinload: 2 запроса (основной + IN).
